# Diffusion of the Tilt Grip Stick: Bass Model Homework

**Author:** Meri Vlasyan

Predicts the diffusion of the Tilt Grip Stick (TIME's Best Inventions of 2025) in the U.S., using the Bass model fitted on U.S. power toothbrush users (Statista, 2012-2020) as the look-alike.

## How to run
1. Install the packages: `pip install pandas numpy scipy matplotlib jupyter`
2. Open `bass_model.ipynb` and run all cells from the project folder.

## Folders
- `bass_model.ipynb`: analysis and written report (Steps 1-7)
- `data/`: power toothbrush users (Statista) and the Grip Stick forecast
- `img/`: charts used in the report
- `report/report.pdf`: PDF export of the notebook
